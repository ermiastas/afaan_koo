# afaan_koo_app

AfaanKoo is an educational platform designed to help children learn Afaan Oromoo through interactive lessons, games, stories, coloring, audio, and other engaging activities. The project has been developed by Raji Ermias with the support and technical contribution of his father, Ermias. After more than one year of development, AfaanKoo continues to grow and remains under active construction, requiring further dedication, testing, educational content, and technical development.
